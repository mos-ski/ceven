# CEven Brand Guide

This folder stores the official CEven brand reference materials.

## Files

- [CEven Brand Guideline 2.pdf](./CEven%20Brand%20Guideline%202.pdf) - Official brand guide.

## How To Use This Guide

The brand guide is the source of truth for CEven's identity: logo usage, brand tone, color intent, typography personality, and visual direction.

The design system is the implementation layer. Components, tokens, layouts, and interaction patterns should reflect the brand guide, but the two documents are not the same thing:

- Brand guide: defines what CEven should feel and look like as a brand.
- Design system: defines how that brand becomes repeatable product UI.

When updating the design system, check this guide first and make sure the final UI still feels aligned with the brand.
